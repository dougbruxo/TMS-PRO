# **App Name**: DezLog Secure Freight

## Core Features:

- User Authentication: User authentication with username and password.
- Admin Password Management: Admin user 'RENATO ADM' can manage user passwords.
- Freight Calculation: Calculate the freight cost based on the information given (distances between the cities, type of vehicle, value of product etc.).
- Vehicle Type Selection: Display of vehicle type options (Fiorino, Van, VUC, Truck, Bi-Truck, Carreta, Carreta LS, Prancha).
- Data Input Form: Form for entering origin and destination, client name, product value, observations, user responsible, and vehicle type.
- Save Quotes: Functionality to save quotes with all the relevant data.
- Filter Quotes: Functionality to filter quotes by the client, the destination or vehicle used.

## Style Guidelines:

- Primary color: Saturated electric blue (#0077FF), reflecting reliability.
- Background color: Light gray (#F0F2F5), maintaining a neutral and clean space.
- Accent color: Desaturated turquoise (#30D5C8), to create visibility on important details.
- Body and headline font: 'Poppins' sans-serif for clear readability and a modern feel.
- Use Font Awesome icons for visual cues within the interface.
- Maintain a clean and organized layout with consistent spacing.
- Subtle transitions and animations to enhance user experience when interacting with elements.
